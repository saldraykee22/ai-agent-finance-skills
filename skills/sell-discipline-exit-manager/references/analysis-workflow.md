# Sell Discipline Workflow

## Exit Types

- Thesis exit: core assumption breaks.
- Risk exit: position exceeds drawdown, concentration, correlation, or volatility limits.
- Liquidity exit: spread, depth, venue, or market conditions deteriorate.
- Event exit: earnings, KAP, unlock, macro, regulation, or corporate action changes risk.
- Profit trim: position is extended, thesis partly priced, or portfolio weight is too high.
- Time stop: expected catalyst fails to occur within the planned horizon.
