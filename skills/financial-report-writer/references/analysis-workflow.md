# Financial Report Writing Workflow

## Formats

- Research note: one asset, thesis, valuation, catalysts, scenarios.
- Morning brief: macro, market moves, calendar, watchlist.
- Event note: what happened, impact, second-order effects, next catalyst.
- Portfolio update: performance, exposure, risk, changes, watchpoints.
- Decision memo: objective, facts, options, trade-offs, chosen action.
- Watchlist summary: candidates, triggers, risks, next data.

## Writing rules

1. Put the conclusion first.
2. Use compact sections and tables for comparisons.
3. Separate facts, calculations, interpretation, scenarios, uncertainties, and next checks.
4. Keep numbers traceable to source/date.
5. Remove filler, generic warnings, and unsupported claims.
6. Match the user's tone: terse trader note, deeper research memo, or executive brief.

## Output format

```text

- ...

- ...

- ...

- Base:

- ...

Next checks:
- ...
```
