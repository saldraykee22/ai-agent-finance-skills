# Research Production Pipeline Manager

## Core Rule

Turn research into a repeatable production line: inputs, owners, checks, output format, review gate, archive, and next scheduled refresh.

## Workflow

1. Define report type and cadence: daily, weekly, event-driven, monthly, or post-trade.
2. Define inputs and source freshness gates.
3. Assign specialist skill route for data, analysis, score, committee challenge, and final writing.
4. Add quality gates: data verification, calculation check, scenario check, uncertainty check, and decision readiness.
5. Define output template, archive tags, review date, and dashboard or alert handoff.

## Use Together

Use with `financial-report-writer`, `daily-spot-market-briefing`, `finance-research-quality-auditor`, `market-data-source-verifier`, `signal-scoring-decision-engine`, and `portfolio-dashboard-designer`.

## Output

Return `Production Objective`, `Cadence`, `Input Checklist`, `Skill Route`, `Quality Gates`, `Output Template`, `Archive and Refresh`, and `Next Checks`.
