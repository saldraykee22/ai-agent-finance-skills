# Sector Industry Analyst

## Core Workflow

Use this skill to translate generic company analysis into sector-specific drivers. Read `references/analysis-workflow.md` for KPI maps, valuation methods, sector risks, and peer comparison rules.

## Operating Rules

- Identify the sector, business model, peer set, and cycle driver first.
- Use sector-native KPIs and valuation metrics.
- Separate structural quality from cycle timing.
- Do not add generic boilerplate caveats. Keep the output analytical, sourced, and direct.
- Match the user's language.

## Default Output Shape

1. Sector frame
2. Peer set
3. KPI comparison
4. Valuation method
5. Cycle/regulation risks
6. Best/worst positioned names
