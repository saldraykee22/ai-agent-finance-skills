# Alert Automation Workflow

## Alert Types

- Price and technical: breakout, breakdown, invalidation, volatility, volume spike.
- Disclosure and event: KAP, SEC, earnings, dividend, split, rights issue, index change.
- Crypto: unlock, exchange listing, delisting, wallet movement, stablecoin depeg, bridge risk.
- Portfolio: concentration drift, cash threshold, drawdown, liquidity breach, FX exposure.
- Data quality: stale source, missing price, conflicting supply, suspicious adjusted series.

## Alert Fields

Alert ID, asset, trigger, source, timestamp rule, severity, action, owner skill, cool-down, last checked, next review.
