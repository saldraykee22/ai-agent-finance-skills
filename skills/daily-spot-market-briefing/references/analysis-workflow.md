# Daily Spot Market Briefing Workflow

## Briefing checks

- BIST:
  - XU100 and sector trend, KAP events, major earnings, dividends, index changes, liquidity measures, USDTRY, rates.
- Crypto:
  - BTC/ETH trend, alt breadth, funding/OI, stablecoin liquidity, on-chain/exchange flows, unlocks, listings/delistings, exchange/custody alerts.
- Global:
  - US indices, DXY, yields, gold/oil, key macro events, risk appetite.
- Portfolio:
  - Current exposure, cash, watchlist states, open event risks, review triggers.

## Daily posture labels

- Attack: regime supportive, liquidity strong, triggers confirmed.
- Selective: trade only best setups.
- Wait: event/regime uncertainty high.
- Defensive: protect cash, reduce weak/illiquid exposure.

## Output format

- ...
