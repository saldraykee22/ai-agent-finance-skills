# Alternative Data Workflow

## Signal Categories

- Demand: app usage, web traffic, search trends, transaction count, customer reviews.
- Developer: commits, releases, issues, protocol integrations, ecosystem grants.
- Community: social growth, engagement quality, governance participation, forum activity.
- Hiring and operations: job postings, store openings, product launches, supplier signals.
- Sentiment: social heat, news tone, influencer concentration, crowding risk.

## Quality Checks

Label each signal as leading, coincident, lagging, noisy, manipulable, or unsupported. Never let sentiment override verified financial, on-chain, liquidity, or portfolio-risk facts.
