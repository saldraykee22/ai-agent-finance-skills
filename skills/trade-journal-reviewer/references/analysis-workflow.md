# Trade Journal Review Workflow

## Required fields when available

- Instrument, direction, setup, thesis, entry, stop/invalidation, target, size, exit, date/time.
- Planned risk, actual loss/profit, R-multiple, holding period, catalyst, screenshots/notes.
- Emotional/process notes: hesitation, FOMO, revenge, rule break, early exit, late entry.

## Metrics

- Win rate, average win, average loss, expectancy, profit factor.
- Average R, max drawdown, streaks, best/worst setup type.
- Planned versus actual risk.
- Rule adherence rate.
- Entry quality, exit quality, thesis validity.

## Review process

1. Normalize trades into comparable fields.
2. Compute metrics if data permits.
3. Group by setup, market regime, asset, timeframe, and catalyst.
4. Identify profitable repeatable behaviors.
5. Identify costly repeated mistakes.
6. Convert observations into rules:
   - Keep doing.
   - Stop doing.
   - Only trade when.
   - Reduce size when.
