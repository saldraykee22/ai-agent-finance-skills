# Spot Trading Playbook Workflow

## Setup types

- Breakout with volume confirmation.
- Pullback to support in uptrend.
- Fundamental catalyst with technical trigger.
- Post-event reset after earnings/KAP/unlock.
- Relative strength leader.
- Deep value with balance sheet survivability.
- Crypto narrative with on-chain confirmation.

## Required setup card

- Asset, venue, currency.
- Thesis.
- Setup type.
- Entry trigger.
- Invalidation.
- First target or review zone.
- Position size and max size.
- Liquidity/execution plan.
- Cost/slippage estimate.
- Event calendar.
- Add/trim/exit rules.
- Post-trade review fields.
