# Economic and Market Calendar Workflow

## Calendar categories

- Macro: CPI, PPI, payrolls, GDP, PMI, retail sales, industrial production, confidence.
- Central banks: decisions, minutes, speeches, balance sheet updates.
- Earnings: report date, call time, guidance, sector bellwethers.
- Corporate actions: ex-dividend, AGM, split, buyback, capital increase, merger vote.
- Crypto: token unlock, governance vote, mainnet upgrade, listing/delisting, airdrop.
- Market structure: index rebalance, futures/options expiry, auction, ETF rebalance.
- Regulation/legal: court date, approval deadline, policy vote, sanction deadline.

## Process

1. Define window: today, this week, month, earnings season, specific holding period.
2. Gather current event dates with sources and time zones.
3. Rank by impact:
   - Direct holdings affected.
   - Macro sensitivity.
   - Expected volatility.
   - Consensus uncertainty.
4. Map preparation:
   - Data to verify before event.
   - Expected scenarios.
   - Position/risk adjustment questions.

## Output format

- ...

- ...
