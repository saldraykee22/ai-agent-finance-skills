# Portfolio Dashboard Workflow

## Core Pages

- Overview: NAV, cash, BIST weight, crypto weight, FX buckets, daily P&L, drawdown, alerts.
- Holdings: position size, cost, unrealized P&L, thesis state, invalidation, liquidity, next event.
- Watchlist: tier, trigger, relative strength, sector or narrative, catalyst, data freshness.
- Risk: concentration, correlation, drawdown, liquidity exit time, stablecoin exposure, counterparty.
- Performance: contribution, benchmark attribution, fees, slippage, realized and unrealized P&L.
- Market regime: BIST, crypto, TRY, rates, USD, commodities, volatility, breadth.
- Journal: setup, process score, R-multiple, execution score, behavior tags.

## Widget Standard

Every widget should define source, timestamp, threshold, interpretation, and next action.
