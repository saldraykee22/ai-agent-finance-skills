# Wallet Operations Workflow

## Controls

- Exchange: unique email, strong password, hardware or app 2FA, withdrawal whitelist, anti-phishing code, device review.
- Self-custody: hardware wallet, seed backup, no screenshots, test transaction, chain verification, address book.
- DeFi: approval review, revoke unused approvals, contract verification, bridge risk, small test first.
- Operations: transfer checklist, incident checklist, backup venue, cold/hot split, stablecoin issuer diversification.

## Incident Plan

Define what to do after phishing suspicion, lost device, compromised exchange login, stuck transfer, wrong chain transfer, stablecoin depeg, or exchange withdrawal freeze.
