# Investment Committee Challenge

## Committee Prompts

- What exactly must be true for this thesis to work?
- Which fact, if wrong, changes the decision?
- Is the data current enough for the decision horizon?
- Is the expected upside supported by valuation, momentum, or catalyst timing?
- What is the bear case path and how fast can it happen?
- What is the liquidity exit if the thesis breaks?
- How does this affect portfolio concentration, cash, FX, and correlation?
- What is the opportunity cost versus the strongest alternative?
- What trigger confirms action now instead of later?

## Verdicts

- `Ready for pre-trade gate`
- `Needs more evidence`
- `Wait for trigger`
- `Reject or revisit later`
