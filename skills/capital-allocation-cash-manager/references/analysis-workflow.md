# Capital Allocation and Cash Workflow

## Allocation buckets

- Core BIST spot.
- Tactical BIST spot.
- Core crypto spot.
- Tactical crypto spot.
- Cash/dry powder.
- Stablecoin or FX bucket.
- Secondary market opportunities.

## Process

1. Identify current exposure by asset, market, currency, exchange, and liquidity.
2. Define target posture:
   - Attack, selective, wait, defensive.
3. Set cash buffer:
   - Higher in defensive/liquidity-stress regimes.
   - Lower only when regime and setups confirm.
4. Allocate opportunity budget:
   - Per idea.
   - Per market.
   - Per theme.
   - Per liquidity bucket.
5. Define deployment:
   - Initial tranche.
   - Add tranche.
   - Max exposure.
   - Stop adding condition.
6. Define rebalance:
   - Concentration breach.
   - Thesis break.
   - Regime change.
   - Better opportunity.
